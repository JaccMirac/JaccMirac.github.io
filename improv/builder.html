So funktioniert's
  • Felder ausfüllen – die Vorschau rechts aktualisiert sich live und sieht aus wie die fertige Session.
  • Mit + Phase / + Spiel / + Block / + Hinweis baust du den Ablauf. Spiele werden je Phase automatisch a) b) c) durchnummeriert.
  • Text hervorheben: **fett** und *kursiv*. Der lila Pfeil zum Lernziel wird automatisch gesetzt.
  • Fertig? HTML herunterladen (zum Hosten/Teilen) oder PDF herunterladen (öffnet den Druckdialog → „Als PDF speichern", A4).
